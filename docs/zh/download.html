核心功能

Terminal

在真实 PTY 环境中运行命令。

Capture

记录结构化执行证据和实际结果。

Changes

查看执行过程中观察到的 Git 仓库变更。

Verify

运行明确的验证检查并保留结果。

在 macOS 上安装

  1. 下载： 下载适用于 Apple Silicon 的 DMG。
  2. 打开： 打开 ExecRelay_0.1.2_aarch64.dmg。
  3. 安装： 将 ExecRelay 拖入 Applications（应用程序）。
  4. 启动： 从 Applications 启动 ExecRelay。

macOS 安全性

ExecRelay Terminal v0.1.2 使用 Developer ID 签名，并已通过 Apple 公证。首次启动时，macOS 会对从互联网下载的应用显示标准确认提示；无需在系统设置中进行任何额外操作。如需确认下载的文件与发布版本一致，请运行 shasum -a 256 ExecRelay_0.1.2_aarch64.dmg，并将结果与以下校验值比对： 8874b532195ef6ac3c3b61f22aaa537e0ce6c5f1dad870c5c50745e600558dbf

  • 架构 Apple Silicon（arm64）

安全与可信模型

ExecRelay 依据原生进程结果和显式验证结果判断工程任务是否成功，而不是从终端文本中推断。

隐私与本地优先

ExecRelay v0.1.2 无需注册 ExecRelay 账号。核心执行在你的本地电脑上进行；除非你在终端中主动使用外部工具，本地工作区数据始终保留在本机应用中。即使遥测失败，正常的终端操作也不受影响。
