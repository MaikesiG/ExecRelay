ExecRelay Terminal v0.1.2

ExecRelay Terminal

运行任何命令。追踪每次执行。验证实际发生了什么。

ExecRelay 是一个本地优先的工程执行终端，不只是运行命令。它将真实 PTY 终端、结构化执行记录、Git 仓库变更观察和显式验证整合在一起，帮助你更清楚地知道实际执行了什么、哪些文件发生了变化，以及任务是否真正成功。

核心功能

四个相互配合的功能区，让工程执行过程透明、可验证。

Terminal

在真实 PTY 环境中运行命令，支持日常命令行工作流、分屏和交互式工具。

Capture

记录结构化执行证据和实际结果，保留真实的进程结果，而不是根据终端文本推断成功与否。

Changes

查看执行过程中观察到的 Git 仓库变更，将文件修改与对应的命令执行关联起来。

Verify

运行明确的验证检查并保留结果，支持确定性的判定条件和 monorepo 工作目录。

可信与验证

以进程结果为准： ExecRelay 依据原生进程结果和显式验证结果判断工程任务是否成功，而不是从终端文本中推断。退出码和进程监控构成判断依据。

本地优先架构

隐私优先设计： ExecRelay v0.1.2 无需注册 ExecRelay 账号。核心执行完全在你的本地电脑上进行；除非你在终端中主动使用外部网络工具，本地工作区数据始终保留在本机应用中。正常的终端操作不依赖遥测功能——即使遥测失败，终端也能继续工作。
