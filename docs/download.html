Installation on macOS

  1. Download: Download the ExecRelay DMG.
  2. Open: Open the downloaded DMG file.
  3. Install: Drag ExecRelay into your Applications folder.
  4. Launch: Launch ExecRelay from Applications.

System Requirements

  • Operating System macOS 11.0 (Big Sur) or later
  • Architecture Apple Silicon (arm64 tested; Intel x86_64 pending)
  • Runtime Engine Native Rust / Tauri v2
  • Account Requirement None (local-first)

Security & Trust Model

ExecRelay uses native process outcomes and explicit verification results rather than inferring engineering success from terminal text.

Privacy & Local-First

ExecRelay v0.2 requires no ExecRelay account. Core execution happens locally on your computer, and local workspace data remains on the local application unless you choose to use external tools from the terminal. Normal terminal operation survives even if telemetry fails.
