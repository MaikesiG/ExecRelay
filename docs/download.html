TECHNICAL BOUNDARIES

Known Limitations

Documented architectural caveats and deferred platform items for v0.2.0.

VERIFY-SHELL-001

Windows Shell Policy

Verification criteria execution requires a POSIX shell or supported runner. Native shell policy interceptors are POSIX/zsh/bash focused; Verify checks do not operate within Windows PowerShell sessions.

WINDOWS-BINARY-NAME-001

Process Details

The Windows executable remains named tracerelay.exe inside %LOCALAPPDATA%\ExecRelay (visible in Task Manager process details and pin targets). User-facing shortcuts, directories, and window chrome display ExecRelay.

WORKSPACE-ROOT-REBIND-001

Cross-Platform Paths

Unreachable local directories or foreign cross-platform workspace paths restore in an unbound state, surfacing an explicit unavailable notice rather than silently mutating paths or creating shells in fallback folders.

Unsigned Installers & Packages

Security Prompts

Windows NSIS installers and Linux packages are unsigned for this release. Verify package checksums against the official SHA256SUMS.txt file before installation.

SURFACES

Core Features

Four integrated surfaces designed for transparent, verified engineering execution.

Terminal

Real PTY-backed engineering terminal for everyday command-line workflows, split panes, and interactive tools.

Capture

Structured evidence for executed commands and observed outcomes, preserving raw process truth without inferring success from terminal text.

Changes

Repository changes observed during execution windows, tracking file modifications alongside process runs via read-only Git collectors.

Verify

Explicit verification checks with retained run history, deterministic criteria evaluations, and monorepo working directory support.

ARCHITECTURE

Security & Trust Model

Process Truth: ExecRelay establishes ground truth from native process supervisory outcomes and explicit verification checks rather than guessing success from terminal text or AI-generated prose. Exit codes and structured execution records remain the authoritative source of truth.
Privacy by Design: ExecRelay requires no account or cloud connection. Execution, transcripts, and repository snapshots remain strictly on your local machine unless a command you run explicitly transmits them. Terminal operation survives even if telemetry fails.
