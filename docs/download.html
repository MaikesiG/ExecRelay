Security & Trust Model

ExecRelay uses native process outcomes and explicit verification results rather than inferring engineering success from terminal text.

Privacy & Local-First

ExecRelay v0.1.2 requires no ExecRelay account. Core execution happens locally on your computer, and local workspace data remains on the local application unless you choose to use external tools from the terminal. Normal terminal operation survives even if telemetry fails.
