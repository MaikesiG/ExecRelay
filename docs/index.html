SURFACES

Core Surfaces

Four integrated surfaces designed for transparent, verified engineering execution.

Terminal

Real PTY-backed engineering terminal for everyday command-line workflows, split panes, and interactive tools.

Capture

Structured evidence for executed commands and observed outcomes, preserving raw process truth without inferring success from terminal text.

Changes

Repository changes observed during execution windows, tracking file modifications alongside process runs via read-only Git collectors.

Verify

Explicit verification checks with retained run history, deterministic criteria evaluations, and monorepo working directory support.

PROCESS TRUTH

Trust & Verification

Process Truth: ExecRelay uses native process outcomes and explicit verification results rather than inferring engineering success from terminal text. Exit codes and process supervision establish ground truth.
PRIVACY

Local-First Architecture

Privacy by Design: ExecRelay requires no account or cloud connection. Core execution runs entirely on your local machine, and local workspace data remains on the local application unless you choose to use external network tools from your terminal. Normal terminal operation remains independent from telemetry features—the terminal survives even if telemetry fails.
